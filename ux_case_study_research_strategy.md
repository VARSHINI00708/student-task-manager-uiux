# User Research Summary: Student Task Manager

## Target Users
- **Primary:** College students aged 18–24.
- **Context:** Juggling multiple courses, part-time jobs, and extracurriculars.

## Goals
- Centralize all academic deadlines in one place.
- Break down large projects into manageable sub-tasks.
- Reduce anxiety surrounding "forgotten" assignments.

## Frustrations
- Fragmented systems (emails, Canvas/Blackboard, physical planners).
- Difficulty estimating how long a task will actually take.
- "Deadline blindness" where multiple tasks collide on the same day.

## Hypothetical Interview Insights
- *"I often forget small quizzes because they're buried in a 20-page syllabus."*
- *"I feel overwhelmed on Sunday nights because I don't know where to start."*
- *"I need a way to see what's due tomorrow versus what's due in two weeks at a glance."*

---

# User Personas

## 1. Procrastinating Paula
- **Age:** 20
- **Major:** Marketing
- **Goals:** Stop missing minor assignment windows; get reminders before it's too late.
- **Pain Points:** Distracted easily; underestimates task complexity.
- **Motivation:** Maintaining a high GPA for her scholarship.

## 2. Overwhelmed Oscar
- **Age:** 22
- **Major:** Engineering
- **Goals:** Visualize his entire semester's exam schedule; manage lab report drafts.
- **Pain Points:** Heavy workload; feels like he's constantly "putting out fires."
- **Motivation:** Getting into a top-tier grad school.

---

# Problem Statement
College students struggle to manage overlapping academic deadlines across multiple platforms, leading to high stress, missed submissions, and poor time management. There is a need for a centralized, low-friction tool that helps them prioritize tasks and visualize their workload.

---

# User Flow
1. **Launch App** -> Splash Screen
2. **Onboarding** -> Login / Sign Up
3. **Dashboard** -> View Upcoming Tasks (Overview)
4. **Action: Add Task** -> Input Title, Course, Due Date, Priority
5. **Action: View Task** -> See Task Details & Sub-tasks
6. **Completion** -> Mark Task as Done -> Visual Confirmation
7. **Management** -> Check Notifications or Update Profile

---

# Information Architecture
- **Level 1: Navigation Bar**
    - Dashboard (Home)
    - Calendar (Schedule)
    - Add (+)
    - Notifications (Alerts)
    - Profile (Settings)
- **Level 2: Task Views**
    - List View (By Date)
    - Course-specific View
    - Task Detail Page

---

# Design Thinking Process
1. **Empathize:** Interviewed students and audited existing LMS apps.
2. **Define:** Focused on "Deadline Blindness" as the core problem.
3. **Ideate:** Sketched solutions for quick entry and visual urgency cues.
4. **Prototype:** Created low-fidelity wireframes focusing on hierarchy.
5. **Test:** (Planned) User testing with students to refine the "Add Task" flow.
